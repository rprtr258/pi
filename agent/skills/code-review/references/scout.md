# Stage 1 — Scout (recon and batch slicing)

Read when stage 1 begins. Dispatch the prompt below verbatim as the subagent task
(`task(prompt=...)`); fill `<<MR_META>>` before dispatch.

## Autogens — always skipped, never enter review

- `*.pb.go`, `*.pb.validate.go`, generated proto/OpenAPI;
- sqlc output: `*_sqlc.go`, `models.go`, `querier.go` (by filename/marker);
- MockGen and mock generators: `mock_*.go`, `*_mock.go`, `mocks/`, `generated-mocks/`;
- `dist/`, `build/`, `output/`, `generated/`, `.nuxt/`, `.next/`;
- manifests: `package-lock.json`, `package-lock.yaml`, `yarn.lock`, `pnpm-lock.yaml`, `go.sum`, `Cargo.lock`;
- locales and reference configs: `locales/*`, `i18n/*` (translations, not code), `docs/*`, README edits;
- files with a marker in the first lines: `Auto-generated ... Do not edit manually!`, `DO NOT EDIT`, `Code generated by ...`.

## Slicing

Batches of 3-15 files; the criterion is a logical module/subsystem (one use case, one
screen, one service layer), not the alphabet. Each batch gets a manifest: `id`, `name`, `severity`
(risk estimate), `files`. A file is never split across batches; each file lands in exactly one
batch. A large MR fits into 10-30 batches.

## Prompt

```
You are the code-review scout. Build a map of the MR's changed files and slice batches.
Input: <<MR_META>>, diff/mr.diff, files_list.txt.
Tasks:
1. List of changed files from the diff (new_path, status).
2. Skip autogens using the universal list: *.pb.go, *_sqlc.go, mock generators,
   dist/ and generated/, package-lock/manifests, locales, reference documentation,
   files with an "Auto-generated / DO NOT EDIT" marker. Skipped files never enter batches.
3. Slice the rest into logical batches of 3-15 files (subsystem/module, not alphabet).
   Manifest: id, name, severity (high/medium/low), files. Each file in exactly one batch.
4. For each batch, cut its diff into fanout/B<NN>.diff (hunks of its files only).
Return: the batch manifest, the number of skipped files, detected_stack.
```
